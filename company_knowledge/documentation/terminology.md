# Terminology

- **Advanced Impactor:** Publicly listed cricket analysis and performance product.
- **CoachPlex:** Publicly listed coaching management platform connecting coaches and athletes.
- **Advanced Impactor Pro:** Public partner-profile name for a multi-sport Academy Management System; relationship to CoachPlex is unverified.
- **RAG:** Retrieval-Augmented Generation; a language model receives retrieved source passages as context before producing an answer.
- **FAISS:** Local vector index used by this repository for dense similarity retrieval.
- **BM25:** Keyword ranking method used by this repository alongside dense search.
- **Release / Pitch / Impact:** Internal delivery-event labels 1, 2, and 3 respectively; label 0 means Random/noise.
- **Historical internal validation figures:** Counts supplied without definitions; not model accuracy.
- **Section citation:** The document and section shown in the UI for a retrieved passage. Public links appear where available.
