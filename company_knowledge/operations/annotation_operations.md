# Annotation operations

## Delivery-event labels
[INTERNAL_CONTEXT] The supplied annotation scheme defines:
- 0 = Random / noise
- 1 = Release
- 2 = Pitch
- 3 = Impact

These are event labels for identifying important delivery points. The brief does not provide timing tolerances, inclusion rules, adjudication steps, or annotation software details.

## Quality practice
[ANALYTICAL] For consistent annotation, document event definitions, annotate edge cases consistently, sample work for review, and record disagreements. Treat these as recommendations unless a current SOP confirms them.
